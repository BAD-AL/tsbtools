QUESTION
  Which sim value do kick and punt returners use? (Open question 3)

WHAT IS DIFFERENT IN THIS ROM
  Baseline (every team, unless changed below): QB [rush 4, pass 8, pocket 3],
  RB/WR/TE [rush 8, catch 8, yards/catch 8, targets 8], defenders [pass rush 30, coverage 30],
  K/P 8, team SimData 0x88, run/pass preference 0. Names and in-game ratings are stock.
  Change: All RB/WR/TE (Sim rush, Sim yards per catch): A = (0, 0), B = (15, 0), C = (0, 15), D = (15, 15). Every skill player on a team is identical, so it does not matter which one is the returner.

GROUPS
  A  (rush 0 / ypc 0): bills, jets, steelers, chargers, eagles, lions, 49ers
  B  (rush 15 / ypc 0): colts, bengals, broncos, seahawks, cardinals, packers, rams
  C  (rush 0 / ypc 15): dolphins, browns, chiefs, redskins, cowboys, vikings, saints
  D  (rush 15 / ypc 15): patriots, oilers, raiders, giants, bears, buccaneers, falcons

HOW TO RUN
  1. Load the ROM in the emulator with fresh save data (delete any old .sav / battery file first).
  2. Start a season and set all 28 teams to be simulated (SKP / computer, as you normally sim a season).
  3. Simulate the full regular season (fast-forward is fine).
  4. Record the season stats below from the team / player stats screens.
     Short on time? Record at least 2 teams per group (8 teams) -- that is usually enough to see the pattern.

WHAT TO EXPECT
  - If returners use Sim rush: B and D return well, A and C poorly.
  - If returners use Sim yards per catch: C and D return well, A and B poorly.
  - If all four groups are the same, the returner value comes from somewhere else (e.g. another player's byte).
