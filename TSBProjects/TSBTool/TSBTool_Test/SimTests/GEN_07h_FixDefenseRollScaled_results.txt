QUESTION
  Stock + GENESIS_FIX_SIM_BUGS + the defense roll using 3/8 of the defense value: normal scoring, smaller spread than GEN_07d?

WHAT IS DIFFERENT IN THIS ROM
  Stock sim data (the game's own values for every team). The stock ROM plus GENESIS_FIX_SIM_BUGS, plus a small routine at 0xDF100 so the defense roll uses defense value * 3/8.

GROUPS
  A  (stock + fix + roll scaled 3/8): bills, jets, steelers, chargers, eagles, lions, falcons
  B  (stock + fix + roll scaled 3/8): colts, bengals, broncos, seahawks, cardinals, packers, rams
  C  (stock + fix + roll scaled 3/8): dolphins, browns, chiefs, cowboys, redskins, vikings, saints
  D  (stock + fix + roll scaled 3/8): patriots, oilers, raiders, giants, bears, buccaneers, 49ers

HOW TO RUN
  1. Load the ROM in the emulator with fresh save data (delete any old .sav / battery file first).
  2. Start a season and set all 28 teams to be simulated (SKP / computer, as you normally sim a season).
  3. Simulate the full regular season (fast-forward is fine).
  4. Record the season stats below from the team / player stats screens.
     Short on time? Record at least 2 teams per group (8 teams) -- that is usually enough to see the pattern.

WHAT TO EXPECT
  - Scoring near GEN_07a; points allowed spread between teams smaller than GEN_07d (sd 59).
  - Save an ares state (.bs1) at the Season Menu after the season: every column can be read from it.
