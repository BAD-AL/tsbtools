QUESTION
  Stock + GENESIS_FIX_SIM_BUGS + the NES run-play yardage cutoffs: how much scoring comes back?

WHAT IS DIFFERENT IN THIS ROM
  Stock sim data (the game's own values for every team). The stock ROM plus GENESIS_FIX_SIM_BUGS, plus the 4 run-play cutoffs set to the NES/SNES values (option 3).

GROUPS
  A  (stock + fix + NES run cutoffs): bills, jets, steelers, chargers, eagles, lions, falcons
  B  (stock + fix + NES run cutoffs): colts, bengals, broncos, seahawks, cardinals, packers, rams
  C  (stock + fix + NES run cutoffs): dolphins, browns, chiefs, cowboys, redskins, vikings, saints
  D  (stock + fix + NES run cutoffs): patriots, oilers, raiders, giants, bears, buccaneers, 49ers

HOW TO RUN
  1. Load the ROM in the emulator with fresh save data (delete any old .sav / battery file first).
  2. Start a season and set all 28 teams to be simulated (SKP / computer, as you normally sim a season).
  3. Simulate the full regular season (fast-forward is fine).
  4. Record the season stats below from the team / player stats screens.
     Short on time? Record at least 2 teams per group (8 teams) -- that is usually enough to see the pattern.

WHAT TO EXPECT
  - More rush yards than GEN_07b; passing about the same as GEN_07b. Probably not enough on its own.
  - Save an ares state (.bs1) at the Season Menu after the season: every column can be read from it.
