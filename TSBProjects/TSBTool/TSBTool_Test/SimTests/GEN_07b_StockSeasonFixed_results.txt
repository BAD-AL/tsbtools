QUESTION
  Does GENESIS_FIX_SIM_BUGS make a stock season too low-scoring (compare with GEN_07a)?

WHAT IS DIFFERENT IN THIS ROM
  Stock sim data (the game's own values for every team). The stock ROM plus the GENESIS_FIX_SIM_BUGS game fix (preference 1 + defense roll); nothing else.

GROUPS
  A  (stock + fix): bills, jets, steelers, chargers, eagles, lions, falcons
  B  (stock + fix): colts, bengals, broncos, seahawks, cardinals, packers, rams
  C  (stock + fix): dolphins, browns, chiefs, cowboys, redskins, vikings, saints
  D  (stock + fix): patriots, oilers, raiders, giants, bears, buccaneers, 49ers

HOW TO RUN
  1. Load the ROM in the emulator with fresh save data (delete any old .sav / battery file first).
  2. Start a season and set all 28 teams to be simulated (SKP / computer, as you normally sim a season).
  3. Simulate the full regular season (fast-forward is fine).
  4. Record the season stats below from the team / player stats screens.
     Short on time? Record at least 2 teams per group (8 teams) -- that is usually enough to see the pattern.

WHAT TO EXPECT
  - Team defense SimData now counts, so good defenses allow less and the spread between teams grows.
  - League points / yards lower than GEN_07a (GEN_05c dropped ~37% vs GEN_05b). If it looks too stingy,
  - restoring the NES run-play cutoffs is the next thing to test.
  - Save an ares state (.bs1) at the Season Menu after the season: every column can be read from it.
