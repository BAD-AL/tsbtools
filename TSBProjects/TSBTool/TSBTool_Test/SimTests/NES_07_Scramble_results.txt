QUESTION
  How often does the QB scramble, and does the pocket value control it? (Open question 2)

WHAT IS DIFFERENT IN THIS ROM
  Baseline (every team, unless changed below): QB [rush 4, pass 8, pocket 3],
  RB/WR/TE [rush 8, catch 8, yards/catch 8, targets 8], defenders [pass rush 30, coverage 30],
  K/P 8, team SimData 0x88, run/pass preference 0. Names and in-game ratings are stock.
  Change: QB1/QB2 Sim pocket = 0 / 1 / 2 / 3 by group, QB Sim rush 15 (so scrambles show up as QB rushing). All teams preference 3 (70% pass).

GROUPS
  A  (Pocket 0): bills, jets, steelers, chargers, eagles, lions, 49ers
  B  (Pocket 1): colts, bengals, broncos, seahawks, cardinals, packers, rams
  C  (Pocket 2): dolphins, browns, chiefs, redskins, cowboys, vikings, saints
  D  (Pocket 3): patriots, oilers, raiders, giants, bears, buccaneers, falcons

HOW TO RUN
  1. Load the ROM in the emulator with fresh save data (delete any old .sav / battery file first).
  2. Start a season and set all 28 teams to be simulated (SKP / computer, as you normally sim a season).
  3. Simulate the full regular season (fast-forward is fine).
  4. Record the season stats below from the team / player stats screens.
     Short on time? Record at least 2 teams per group (8 teams) -- that is usually enough to see the pattern.

WHAT TO EXPECT
  - Code as read (lookup then AND #3): chance per pass play = pocket 0: 3/256, 1: 1/256, 2: 1/256, 3: 0.
  -   -> with ~400 pass plays per team-season: A ~4-5 QB runs, B and C ~1-2, D 0.
  - If instead the table is meant as-is (51/25/13/8 out of 256): A ~80, B ~40, C ~20, D ~12 QB runs per season.
  - Group D (pocket 3) QB runs, if any, come from designed runs, not scrambles.
