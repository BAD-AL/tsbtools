QUESTION
  Does a receiver's 3rd sim value (Sim yards per catch, formerly labeled "punt ret") control yards after the catch? (Open question 1)

WHAT IS DIFFERENT IN THIS ROM
  Baseline (every team, unless changed below): QB [rush 4, pass 8, pocket 3],
  RB/WR/TE [rush 8, catch 8, yards/catch 8, targets 8], defenders [pass rush 30, coverage 30],
  K/P 8, team SimData 0x88, run/pass preference 0. Names and in-game ratings are stock.
  Change: All RB/WR/TE Sim yards per catch = 0 / 5 / 10 / 15 by group. All teams preference 3 (70% pass).

GROUPS
  A  (Sim yards/catch 0): bills, jets, steelers, chargers, eagles, lions, 49ers
  B  (Sim yards/catch 5): colts, bengals, broncos, seahawks, cardinals, packers, rams
  C  (Sim yards/catch 10): dolphins, browns, chiefs, redskins, cowboys, vikings, saints
  D  (Sim yards/catch 15): patriots, oilers, raiders, giants, bears, buccaneers, falcons

HOW TO RUN
  1. Load the ROM in the emulator with fresh save data (delete any old .sav / battery file first).
  2. Start a season and set all 28 teams to be simulated (SKP / computer, as you normally sim a season).
  3. Simulate the full regular season (fast-forward is fine).
  4. Record the season stats below from the team / player stats screens.
     Short on time? Record at least 2 teams per group (8 teams) -- that is usually enough to see the pattern.

WHAT TO EXPECT
  - If the value is yards per catch: yards per completion rises A -> D, completions stay about the same.
  - If it were punt returns (old label): PR yards would change instead and yds/comp would stay flat.
