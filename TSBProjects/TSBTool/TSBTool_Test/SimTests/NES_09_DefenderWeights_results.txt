QUESTION
  Do defenders' Sim pass rush / Sim coverage only decide WHO gets sacks and INTs, not how many? Which byte drives which? What happens to leftover weight? (Open question 4)

WHAT IS DIFFERENT IN THIS ROM
  Baseline (every team, unless changed below): QB [rush 4, pass 8, pocket 3],
  RB/WR/TE [rush 8, catch 8, yards/catch 8, targets 8], defenders [pass rush 30, coverage 30],
  K/P 8, team SimData 0x88, run/pass preference 0. Names and in-game ratings are stock.
  Change: Defender [pass rush, coverage]: A = everyone [23, 23]; B = pass rush RE 255, others 0 / coverage LE 255, others 0; C = everyone [0, 0]; D = everyone [200, 200].

GROUPS
  A  (all [23,23]): bills, jets, steelers, chargers, eagles, lions, 49ers
  B  (RE rush 255 / LE cover 255, rest 0): colts, bengals, broncos, seahawks, cardinals, packers, rams
  C  (all [0,0]): dolphins, browns, chiefs, redskins, cowboys, vikings, saints
  D  (all [200,200]): patriots, oilers, raiders, giants, bears, buccaneers, falcons

HOW TO RUN
  1. Load the ROM in the emulator with fresh save data (delete any old .sav / battery file first).
  2. Start a season and set all 28 teams to be simulated (SKP / computer, as you normally sim a season).
  3. Simulate the full regular season (fast-forward is fine).
  4. Record the season stats below from the team / player stats screens.
     Short on time? Record at least 2 teams per group (8 teams) -- that is usually enough to see the pattern.

WHAT TO EXPECT
  - How credit is picked (code $9789 / $9802): random 0-255, take each of the first 10 defenders (RE, NT, LE, ROLB, RILB, LILB, LOLB, RCB, LCB, FS) in turn: if the number is below his value he gets it, otherwise subtract his value and go on. Whatever is left goes to the SS. Stock teams' 11 values add up to 255.
  - If the values only pick WHO gets credit: team sacks and team INTs about the same in all four groups.
  - A: sacks/INTs spread about evenly (about 9% each; SS a little more).
  - B: the RE gets every sack and the LE every INT -- shows pass rush drives sacks, coverage drives INTs.
  - C: the SS gets every sack and every INT (all the weight is leftover).
  - D: the RE gets about 78% and the NT about 22% of both; nobody else gets any (values are not scaled when the total is over 255).
