QUESTION
  Stock + GENESIS_FIX_SIM_BUGS + defense roll value - 83 + run cutoffs halfway to NES: stock scoring without the GEN_07g run inflation?

WHAT IS DIFFERENT IN THIS ROM
  Stock sim data (the game's own values for every team). The stock ROM plus GENESIS_FIX_SIM_BUGS, plus the GEN_07d routine at 0xDF100 (defense value - 83) and run-play cutoffs 39/71/A9/D2.

GROUPS
  A  (stock + fix + roll offset 83 + midpoint run cutoffs): bills, jets, steelers, chargers, eagles, lions, falcons
  B  (stock + fix + roll offset 83 + midpoint run cutoffs): colts, bengals, broncos, seahawks, cardinals, packers, rams
  C  (stock + fix + roll offset 83 + midpoint run cutoffs): dolphins, browns, chiefs, cowboys, redskins, vikings, saints
  D  (stock + fix + roll offset 83 + midpoint run cutoffs): patriots, oilers, raiders, giants, bears, buccaneers, 49ers

HOW TO RUN
  1. Load the ROM in the emulator with fresh save data (delete any old .sav / battery file first).
  2. Start a season and set all 28 teams to be simulated (SKP / computer, as you normally sim a season).
  3. Simulate the full regular season (fast-forward is fine).
  4. Record the season stats below from the team / player stats screens.
     Short on time? Record at least 2 teams per group (8 teams) -- that is usually enough to see the pattern.

WHAT TO EXPECT
  - About 20 pts/game and about 130 rush yds/game (GEN_07d 18.3 / 115, GEN_07g 21.7 / 152), defense effect like GEN_07d.
  - Save an ares state (.bs1) at the Season Menu after the season: every column can be read from it.
