QUESTION
  GEN_07i + pass defense value - 135 on the main pass play: stock-level passing (comp% ~75, more 1000-yard receivers)?

WHAT IS DIFFERENT IN THIS ROM
  Stock sim data (the game's own values for every team). Same as GEN_07i, plus a routine at 0xDF110 so the main pass play takes 52 more off the pass defense value (135 in all).

GROUPS
  A  (GEN_07i + pass defense -135): bills, jets, steelers, chargers, eagles, lions, falcons
  B  (GEN_07i + pass defense -135): colts, bengals, broncos, seahawks, cardinals, packers, rams

  D  (GEN_07i + pass defense -135): patriots, oilers, raiders, giants, bears, buccaneers, 49ers

HOW TO RUN
  1. Load the ROM in the emulator with fresh save data (delete any old .sav / battery file first).
  2. Start a season and set all 28 teams to be simulated (SKP / computer, as you normally sim a season).
  3. Simulate the full regular season (fast-forward is fine).
  4. Record the season stats below from the team / player stats screens.
     Short on time? Record at least 2 teams per group (8 teams) -- that is usually enough to see the pattern.

WHAT TO EXPECT
  - More passing than GEN_07j; pass defense digits 0-2 all count as 0.
  - Save an ares state (.bs1) at the Season Menu after the season: every column can be read from it.
