QUESTION
  How much do teams score in a stock Genesis season (the game's own sim data, no fixes)? Baseline for GEN_07b.

WHAT IS DIFFERENT IN THIS ROM
  Stock sim data (the game's own values for every team). Nothing: this is the stock ROM, byte for byte.

GROUPS
  A  (stock): bills, jets, steelers, chargers, eagles, lions, falcons
  B  (stock): colts, bengals, broncos, seahawks, cardinals, packers, rams
  C  (stock): dolphins, browns, chiefs, cowboys, redskins, vikings, saints
  D  (stock): patriots, oilers, raiders, giants, bears, buccaneers, 49ers

HOW TO RUN
  1. Load the ROM in the emulator with fresh save data (delete any old .sav / battery file first).
  2. Start a season and set all 28 teams to be simulated (SKP / computer, as you normally sim a season).
  3. Simulate the full regular season (fast-forward is fine).
  4. Record the season stats below from the team / player stats screens.
     Short on time? Record at least 2 teams per group (8 teams) -- that is usually enough to see the pattern.

WHAT TO EXPECT
  - Normal-looking Genesis scores. Compare the league totals with GEN_07b.
  - Save an ares state (.bs1) at the Season Menu after the season: every column can be read from it.
