QUESTION
  Stock + GENESIS_FIX_SIM_BUGS + team defense tables shifted down (rush -82, pass -84): normal scoring with defense still mattering?

WHAT IS DIFFERENT IN THIS ROM
  Stock sim data (the game's own values for every team). The stock ROM plus GENESIS_FIX_SIM_BUGS, plus the defense value tables at 0xDE9BA / 0xDE9CA lowered (option 1).

GROUPS
  A  (stock + fix + shifted tables): bills, jets, steelers, chargers, eagles, lions, falcons
  B  (stock + fix + shifted tables): colts, bengals, broncos, seahawks, cardinals, packers, rams
  C  (stock + fix + shifted tables): dolphins, browns, chiefs, cowboys, redskins, vikings, saints
  D  (stock + fix + shifted tables): patriots, oilers, raiders, giants, bears, buccaneers, 49ers

HOW TO RUN
  1. Load the ROM in the emulator with fresh save data (delete any old .sav / battery file first).
  2. Start a season and set all 28 teams to be simulated (SKP / computer, as you normally sim a season).
  3. Simulate the full regular season (fast-forward is fine).
  4. Record the season stats below from the team / player stats screens.
     Short on time? Record at least 2 teams per group (8 teams) -- that is usually enough to see the pattern.

WHAT TO EXPECT
  - Scoring back near GEN_07a (about 20 pts/game; GEN_07b had 12.8) with defense digits still mattering.
  - These tables are also read by 3 other plays (not just the defense roll), so those change too.
  - Save an ares state (.bs1) at the Season Menu after the season: every column can be read from it.
