    How this works

    You're editing only the logo drawn on the big helmet. The shell and facemask show faintly as a guide and aren't changed here. Nothing touches the ROM until you click Apply logo.

    1. Draw. Pick one of the 3 logo colors below, then draw on the helmet. Change color… changes what that color looks like. Only this team uses these colors. Pencil draws pixels (right-click erases), Fill fills an area, and Pick picks up a color from the logo. Ctrl+Z undoes.
    2. Move pieces (optional). With Move, drag a yellow box: the sprite and the pixels in it move together and come to the front. Click a box, then use the arrow keys to nudge it 1 pixel, or Shift+arrow for 8.
    3. Watch the fit check under the buttons. Green "Fits" means the ROM can hold the logo. Red means it can't yet, and says why.
    4. Apply logo puts it in the target ROM. Then use Save target ROM as… at the top. The main Undo takes it back.

    Why a logo might not fit. The NES draws the logo from 8×8 tiles called sprites, shown as yellow boxes. A helmet has room for about 20 of them, and only 8 can sit side by side on one row. Boxes stay where they are. Pixels you draw outside every box get a new box. To fit, keep the logo compact and avoid wide rows. Moving boxes so they line up or overlap less can also help, and Auto-arrange sprites lets the editor choose the boxes again. The original 28-team ROM also has little spare tile space, so changing pixels inside existing boxes fits better than adding new ones.

    Using another paint program. Export PNG saves a 72×84 picture with a transparent background: the logo on top, and a strip below with blocks for colors 1, 2 and 3. Edit it, keeping the size and position, then Import PNG….

    • Use the eyedropper on the strip to draw in the exact logo colors. Each pixel snaps to the closest strip color, so draw with hard edges and no smoothing.
    • To change a logo color, repaint its block and the pixels that use it. The editor switches to the closest NES color.
    • Without the strip, e.g. a 72×72 picture, the editor's current colors are used. If the picture has no transparency, its corner color counts as background.

      How this works

      This edits the small helmet on the team-select grid by changing the pixels of the graphics tiles it is drawn from. Nothing touches the ROM until you click Apply.

      1. Pick a layer. Background is the helmet's 16×16 shell and logo, made of four tiles. Overlay is the extra sprites some teams draw on top (a logo, or the shell's body color). Hatched or dimmed areas have no tile there and can't be drawn on.
      2. Draw. Pick a color 1-3 (none is clear). Pencil draws (right-click erases), Fill fills an area, Pick picks up a color. Ctrl+Z undoes. Palette group chooses which of the screen's four color sets this helmet uses. The colors in each set are shared by every helmet.
      3. Watch the warning. Many teams draw the same tiles (ears, facemask, plain shell pieces). If the edit touches one, the other teams that use it change too, and the notes say which.
      4. Apply puts the edit in the target ROM. Then use Save target ROM as… at the top. The main Undo takes it back.

      Using another paint program. Export PNG saves a 24×36 picture: the background layer on top, then the overlay layer, with a transparent backdrop and this helmet's own colors. Edit it keeping the size and position (a scaled-up copy also works), then Import PNG…. Each pixel snaps to the closest of the layer's three colors, so draw with hard edges and no smoothing.

        TSB Helmet Editor

        Copy, paste and edit the helmets in NES Tecmo Super Bowl ROMs: the original 28-team game and the 32-team version.

        Getting started

        • Open two ROMs. Source is where you copy helmets from; Target is the ROM you change. Click Open ROM…, or drop a .nes file anywhere on the page (it goes to the first empty pane; drop it on a pane to replace that one).
        • Right-click any helmet for its options. Clicking a source helmet copies it; clicking a target helmet pastes the copy there.
        • Save. Edits happen in memory. Save target ROM as… downloads the edited ROM and never touches your original file. Undo steps back through the changes you applied. Helmets with a dot have been changed. Use target ROM copies the edited target into Source, so you can copy between versions of your work.
        • Your ROMs stay on your computer. They are read in the browser and never uploaded.

        Large helmets (the team data screen)

        • Copy / paste. A preview shows before and after. Choose what to bring over: the logo, the colors, the shell. It tells you if the ROM can't hold the logo, or if other teams share it.
        • Edit colors… changes the team's helmet colors. Only that team uses them.
        • Edit logo… is a pixel editor for the logo: pencil, fill, pick, move the sprites, a live fit check, and PNG export / import to work in another paint program.
        • Export all logos (PNG) saves every team's logo in one zip.

        Small helmets (the team-select grid)

        • Copy / paste / Edit small helmet… work the same way from the right-click menu.
        • The editor changes the graphics tiles directly, in two layers: Background (the 16×16 shell and logo) and Overlay (extra sprites some teams draw on top). You can also pick the helmet's palette group and export / import a PNG.
        • Shared tiles. Many teams draw the same tiles (ears, facemask, plain shell pieces). If your edit touches one, the notes list the other teams that change with it.

        The look

        • Style: Modern, or NES (chunky pixel borders and the game's font). Team colors: pick any of the 32 teams to color the whole page. Mode: Light, Dark, or Auto (follows your computer). NES is always dark. Your choices are remembered.

        Tips

        • In the editors, Ctrl+Z undoes, and P F I pick Pencil, Fill and Pick.
        • Press ? any time to open this help.
